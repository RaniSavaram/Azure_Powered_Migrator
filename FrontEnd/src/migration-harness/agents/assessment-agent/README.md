# Assessment Agent

## Purpose
Computes migration complexity scores, workload sizing, table dependency graphs, and risk ratings — generating comprehensive readiness reports.

## How to Attach Chatbot / Workflow
- **Template**: Edit `assessment-agent.component.html` in the `.workspace-canvas` area to embed your chatbot component, message history, and input field.
- **Logic**: Add your state and service calls in `assessment-agent.component.ts`.
