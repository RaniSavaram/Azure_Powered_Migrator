# Discovery Agent

## Purpose
Analyse source platform, extract full schema inventory, row counts, data types, ER relationships, and compliance signals.

## How to Attach Chatbot / Workflow
- **Template**: Edit `discovery-agent.component.html` in the `.workspace-canvas` area to embed your chatbot component, message history, and input field.
- **Logic**: Add your state and service calls in `discovery-agent.component.ts`.
