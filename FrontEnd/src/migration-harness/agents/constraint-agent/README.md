# Constraint Agent

## Purpose
Enforces schema constraints, primary & foreign key preservation, unsupported data type detection, and enterprise governance policies.

## How to Attach Chatbot / Workflow
- **Template**: Edit `constraint-agent.component.html` in the `.workspace-canvas` area to embed your chatbot component, message history, and input field.
- **Logic**: Add your state and service calls in `constraint-agent.component.ts`.
