# Artifacts Generator

## Purpose
Compiles migration deliverables into exportable artifacts — including Microsoft Fabric item JSONs, SQL DDL bundles, and assessment documentation.

## How to Attach Chatbot / Workflow
- **Template**: Edit `artifacts-generator.component.html` in the `.workspace-canvas` area to embed your chatbot component, message history, and input field.
- **Logic**: Add your state and service calls in `artifacts-generator.component.ts`.
