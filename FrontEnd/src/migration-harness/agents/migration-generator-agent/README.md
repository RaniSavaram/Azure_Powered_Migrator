# Migration Generator Agent

## Purpose
Converts legacy ETL code, stored procedures, views, and schemas into production-ready Microsoft Fabric Lakehouse/Warehouse SQL and Databricks Asset Bundles.

## How to Attach Chatbot / Workflow
- **Template**: Edit `migration-generator-agent.component.html` in the `.workspace-canvas` area to embed your chatbot component, message history, and input field.
- **Logic**: Add your state and service calls in `migration-generator-agent.component.ts`.
